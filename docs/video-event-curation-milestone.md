# Event curation milestone

An event is **Curation complete — reviews and excerpts collected** when its
current included performance groups are nonempty and every group has complete
reviews under the existing Weaver policy plus at least one saved excerpt.
Explicitly linked format variants remain one performance group.

This status is calculated from current records, not a manually persisted close
operation. A new included performance without review/excerpt coverage returns
the event to curation in progress. Empty events never count as complete.

The **Curation complete** view shows those events and their videos. They leave
the active review event picker, but remain available through Video library,
My reviewed videos and existing task URLs. A personally finished review remains
separate from whole-event completion.

This milestone does not approve excerpts, certify intake completeness, close
Footage Management, remove holds, change scores/rights, send anything to Poetry
Please, or assert editing/calendar readiness. Those statuses remain independent.
No existing records are rewritten and there is no undo action to perform.

Verified live coverage before implementation, November 23, 2026:
BPL Charm City 54/54, MN Writers Respond 12/12, MPMU Finals 16/16,
Ollie Action Cam 11/11 and Publisher’s Poetry Slam 22/22 have complete reviews
and at least one saved excerpt per entry. These are current included performance
entries, not counts of physical format variants.

Validation: focused milestone, personal queue, event receiver/restart,
format-family and runtime image dependency tests. Live deployment must be
verified separately; this document does not claim the feature is live.
